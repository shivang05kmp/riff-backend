# Docs

Written documentation for Riff. Each item below is created when its first file is written.

| Item | What goes in it | First used |
| --- | --- | --- |
| `requirements.md` | what Riff must do (features) and how well (speed, scale, reliability) | Day 1 |
| `adr/` | Architecture Decision Records: one short file per important decision and why it was made | Week 1 |
| `api/` | API contracts and example requests | Day 3 |
| `design/` | design docs and system diagrams | Day 18 |
| `runbooks/` | step-by-step guides for when something breaks | Day 36 |
